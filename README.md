## About me

I'm Gabriel Azevedo, an Information Systems student and fullstack developer focused on building real products, internal tools and intelligent systems.

My current focus is the intersection between **software engineering, AI agents, automation, product design and personal productivity systems**. I like creating tools that do more than look good — they need to execute, remember, validate, automate and solve real problems.

Right now, I'm building **OrcTech**, my personal creation lab powered by AI agents, and **Fawkes**, my personal assistant designed to become a local companion for my computer.

---

## Currently building

### OrcTech — Personal Creation Lab

A personal creation laboratory designed to transform ideas into real projects through agents, memory, automation and execution.

OrcTech is not just a coding assistant. It is being built as a private workspace where I can create, plan, execute, review and evolve projects across different areas.

Core ideas:

- Multi-agent workflow
- Real code execution
- Project memory
- QA and Security gates
- Cost and budget control
- CLI fallback
- Remote approval
- Visual pipeline
- Personal creation modes
- Fawkes integration

---

### Fawkes — Personal AI Assistant

A personal assistant designed to run as a local companion for my computer.

The goal is to make Fawkes work beyond a normal chat interface: listening, acting, remembering context, triggering actions and connecting with OrcTech.

Main ideas:

- Voice interaction
- WebSocket communication
- Local memory
- TTS
- Action execution
- Project context
- Local/remote AI model routing
- Future daemon/terminal mode
