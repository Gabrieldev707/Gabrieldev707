## About me

I’m Gabriel Azevedo, an Information Systems student and fullstack developer based in Campina Grande, Brazil.

My focus is the intersection between **software engineering, AI agents, automation and product design**. I like building things that go beyond the interface — systems that understand context, execute with control and feel personal.

I don’t just implement features. I design workflows, model data, think about security, and care about the user’s experience from the first screen to the last API call.

Currently building two flagship projects: **OrcTech**, an agentic creation lab powered by AI, and **Fawkes**, a local AI companion for my computer.

-----

## Currently building

### OrcTech — Agentic Creation Lab

A private workspace where ideas become real projects through AI agents, memory and automated execution.

OrcTech operates as a multi-agent pipeline: from intake and planning to code execution, QA gates, security review and delivery. Every project runs through structured phases with cost control, remote approval and CLI fallback.

> Multi-agent workflow · Real code execution · Project memory · QA & Security gates · Budget control · Visual pipeline · Fawkes integration

-----

### Fawkes — Personal AI Assistant

A local AI companion designed to listen, act, remember and connect.

Fawkes runs beyond a chat interface — it uses voice interaction, WebSocket communication, local memory and TTS to feel like a real presence on my machine. Integrated with OrcTech for project context and action execution.

> Voice · WebSockets · Local memory · TTS · Action execution · Local/remote AI routing · Future daemon mode
